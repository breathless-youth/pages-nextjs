# 랜딩 시안 10종 — V1.0 디자인 반영 + SEO 보강 설계

2026-07-26. 앱 V1.0 디자인 확정(Standalone HTML 4종 + `.ai/product/design.md`)에 따라, 시안 10종(`/intro/*`)의 앱 목업·용어·섹션을 전면 갱신한다. 시안 선택은 아직이므로 10종 모두에 동일하게 적용한다.

## 범위

1. **앱 목업 재구현** — 공용 컴포넌트 교체로 10종 전체 반영
2. **용어·카피 교정** — glossary 확정 용어를 10종 전체에 적용
3. **SEO 섹션 추가** — FAQ·기능 그리드를 공통 데이터로 정의, 시안별 스타일로 렌더
4. **SEO 인프라** — JSON-LD, noindex 전략, `site.ts` 교정

하지 않는 것: 시안 자체의 레이아웃·무드 변경(10종의 개성 유지), `/` 허브 개편(시안 선택 후 승격 시점에), 가격 관련 문구(미확정), 사전등록/이메일 수집(백엔드 없음).

## 1. 앱 목업 (components/app/)

공통 원칙: Pretendard(이미 로드됨), 확정 문구는 `voice-tone.md` 그대로, 이모지 금지(불꽃은 2톤 SVG), 타이머 `HH:MM:SS` tabular-nums. 컬러는 스크린샷 기준 — brand `#3182F6` 계열, 세션 다크 `#0B0F14`, 세션 오버레이 집중 `#4593FC` · 비집중 `#FF9E1B` · 일시정지 `#8B95A1`.

### AppHomeScreen (S1)

위→아래:
- 헤더: "FocusON" 로고 텍스트 + "7월 25일 토요일"
- 히어로 카드: 라벨 "오늘 순공시간" · 대형 "3시간 42분" · 구간 눈금 게이지(채움 71% = 집중률) · 하단 "총 공부 5시간 12분" + "71% 집중" 필
- 집중 시작 카드(브랜드 블루): "집중 시작" + 서브 "누르면 바로 측정이 시작돼요" + 플레이 원형. 카드 아래 캡션 "카메라가 자동으로 측정해요 · 영상은 저장되지 않아요"
- 스탯 2카드: **연속 공부**(2톤 불꽃 SVG) 값 "12일째" + 서브 "하루 10분이면 유지돼요" / **최장 집중** "52분" + "오늘 가장 길게 집중했어요"
- 가이드 카드: "내 진짜 순공시간, 어떻게 재는 걸까요?" + CTA "지금 확인해 보세요" + 잉크 두들 스타일 미니 SVG(책상 인물)
- 탭바: 홈(활성)·기록·설정

### AppTimerScreen (S3)

- 다크 `#0B0F14` 배경(카메라 프리뷰 대체 질감 유지), 상단 중앙 **상태 필**(다크 글래스, 점+문구), 중앙 발광 타이머(색=상태색), 아래 "총 HH:MM:SS" 병기, 캡션 "영상은 기기 안에서만 처리돼요"
- 하단 **컨트롤 바**(라운드 바 + 핸들): 일시정지 / 카메라 전환 / 종료(레드) 아이콘
- 라이브 데모 시나리오 유지(집중 9s → 휴대폰 4s → 집중 7s → 자리 이탈 5s), 상태 문구를 확정 문구로 교체:
  - 집중: "집중 측정 중" (블루)
  - 휴대폰: "휴대폰을 사용 중인 것 같아요" (오렌지)
  - 자리 이탈: "자리를 비운 것 같아요" (오렌지)
- 비집중 시: 순공 타이머 정지 + 흐림, 총 공부는 계속 진행 (현행 로직 유지)

### AppResultScreen (S4)

- 타이틀 **"공부 결과"** + 닫기 X
- 헤더: 라벨 "순공시간" · "1시간 24분" + "80% 집중" 필 · "총 공부 1시간 45분 · 21:03 – 22:51"
- 타임라인: **3색**(집중 블루 · 비집중 오렌지 · 일시정지 회색) + 범례 3개
- 비집중 내역 "비집중 21분": 자리 이탈 2회 · 9분 40초 / 휴대폰 사용 2회 · 6분 12초 / 기기 조작 1회 · 5분 12초 + **일시정지 행(회색)** "일시정지 1회 · 3분" — 구버전 "화면 꺼짐" 행 삭제
- CTA "확인"
- 수치 정합성: 순공 1:24:08 + 비집중 21:04 = 총 공부 1:45:12(집중률 80%). 일시정지 3분은 총 공부에 미포함이므로 시각 범위는 21:03 – 22:51(1시간 48분 경과)

### AppRecordsScreen (S5 — 신규)

- 연속 공부 배너: 불꽃 SVG + "12일 연속 공부 중" + "내일도 10분만 하면 이어져요" + 주간 체크 도트
- 월 달력(7월): 기록일 하단 도트, 선택일(25) brand 채움, 오늘 brand 테두리, 미래 비활성
- "7월 25일 학습 요약" 2×2 스탯: 순공시간 3시간 42분(brand 강조) · 총 공부 5시간 12분 · 집중률 71% · 공부 3회
- 공부 기록 리스트 1~2건(최신순): 순공 값 강조 + 시간대·총 + 집중률 + 비집중 뱃지("자리 이탈 N회" 등)
- 탭바: 기록 활성

## 3. 공통 콘텐츠 데이터 (lib/content.ts — 신규)

### FAQ 8문항 (토스 라이팅 톤 · 해요체 · "감지" 미사용)

1. **순공시간은 어떻게 재나요?** — 전면 카메라와 센서가 자리 이탈·휴대폰 사용·기기 조작을 기기 안에서만 측정해요. 집중이 아니면 순공 타이머가 저절로 멈추고, 다시 집중하면 이어서 올라가요. 눌러야 할 건 없어요.
2. **카메라 영상이 저장되거나 전송되나요?** — 아니요. 측정은 전부 기기 안에서 끝나고, 영상은 저장하지도 기기 밖으로 보내지도 않아요. 남는 건 공부 시간 기록뿐이에요.
3. **회원가입이 필요한가요?** — 필요 없어요. 설치하면 바로 시작할 수 있어요. 로그인은 이후 업데이트에 추가되고, 지금까지의 기록도 로그인하면 계정에 그대로 이어져요.
4. **카메라 권한을 허용하지 않으면 못 쓰나요?** — 쓸 수 있어요. 수동 타이머 모드로 직접 시작·종료하며 순공시간을 재고, 통계와 연속 공부도 똑같이 쓸 수 있어요.
5. **잠깐 자리를 비우면 어떻게 되나요?** — 자리를 비우면 순공 타이머만 멈추고, 돌아오면 자동으로 다시 측정돼요. 쉴 때는 일시정지를 누르면 순공시간과 총 공부 시간이 모두 멈춰요.
6. **인터넷이 없어도 되나요?** — 네, 측정은 네트워크 없이 완전히 동작해요. 기록은 기기에 먼저 저장하고, 연결되면 자동으로 옮겨 둬요.
7. **어떤 기기에서 쓸 수 있나요?** — iPhone과 Android 모두 준비하고 있어요. App Store와 Google Play 출시를 준비 중이에요.
8. **기록에는 뭐가 남나요?** — 순공시간·총 공부 시간·집중률과 비집중 내역(자리 이탈·휴대폰 사용·기기 조작)이 공부 단위로 남고, 달력에서 날짜별로 볼 수 있어요.

### 기능 그리드 (롱테일 키워드 커버)

심플 모드(탭 한 번, 타이머만 크게) · 가로 거치 모드 · 라이트/다크 모드 · 오프라인 완전 동작 · 수동 타이머 모드 · 자동으로 다시 측정(비집중이 끝나면 저절로 이어짐). 각 항목 1줄 설명.

## 4. SEO 인프라

- **JSON-LD 컴포넌트** (`components/seo/JsonLd.tsx`): `MobileApplication`(name FocusON, OS iOS/Android, 카테고리 EducationalApplication) + `FAQPage`(위 8문항). 10종 모두 삽입 — 승격 시 그대로 사용.
- **noindex**: `/intro/*` 10종 전체 `robots: { index: false, follow: false }` 추가. 시안 선택 전 중복 콘텐츠 10벌이 인덱싱되는 것 방지. 승격 시 해당 시안에서 제거.
- **sitemap/robots**: `/intro/*`가 sitemap에 있으면 제외. `/`·`/privacy`·`/terms`·`/support`만 유지.
- **metadata**: 시안별 title 유지. description은 핵심 키워드(순공시간, 순공 타이머, 공부 타이머, 집중 측정) 자연 포함으로 통일감 있게 다듬기.
- 콘텐츠 페이지(블로그 등) 추가는 이번 범위 아님 — 출시 후 검토.
